    COMPILE-TIME CONTRACTS DEMO

    COMPILE-TIME CONTRACTS DEMO

    This example demonstrates FlowForge's unique USP: "Pipelines will not even build if source or target schema do not match or align."

    Following CONTRIBUTING.md principles:

    • Pure functional pipeline composition
    • Phantom types for compile-time safety
    • Immutable data structures
    • Type-safe resource management
    • First-class functions

    KEY FEATURES DEMONSTRATED:

    1. Phantom-state builder pattern prevents incomplete pipelines 2. SchemaConforms evidence enforces schema compatibility 3. Explicit SchemaPolicy parameters for all typed endpoints 4. Pipeline build() is only available when all stages are complete

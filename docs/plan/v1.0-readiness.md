# FlowForge v1.0.0 Readiness - Gaps, Risks, and Fix Plan (2025-10-02)

This document is the single source of truth for v1.0 readiness. It captures blocking and high‑priority items across architecture, design, build/CI, docs, and DX. Dates are explicit to avoid ambiguity.

## Summary
- Target: v1.0.0 stable, publishable artifacts, Scala 2.13 primary; Scala 3 support for core (no Spark), JDK 17 baseline.
- USP: Compile‑time data contracts (SchemaConforms) + fiber‑safe pipelines; batteries‑included framework (not a bag of libs).

## Blocking Gaps (must‑fix before v1.0)
- Build/CI JDK mismatch
  - Gap: CI used JDK 21; Spark 3.5.x supports up to Java 17. Fix committed: CI/release now use JDK 17.
  - Risk: Runtime failures in engines‑spark tests on CI. Mitigation: enforce 17 everywhere (docs + sbt javaOptions are fine).
- Flink cross‑build invalid
  - Gap: `engines-flink` declared `2.12, 2.13`. Flink Scala API is 2.12‑only. Fix committed: limit to 2.12.
  - Risk: Broken CI/false red. Mitigation: module‑scoped cross settings and explicit note in ADR.
- Legacy shapeless witness present on Scala 3 path
  - Gap: `SchemaWitness` required shapeless on all Scala versions. Fix committed: move to `scala-2` sources + add shapeless 2.3.10 in Scala‑2 deps only.
  - Risk: Scala 3 compile failures. Mitigation: isolate file; long‑term: remove after migration.
- Contracts codegen coupling to shapeless
  - Gap: Generator emitted `LabelledGeneric` alias. Fix committed: emit minimal case class only (macro‑friendly for `SchemaConforms`).
  - Risk: Unnecessary dependency + confusion. Mitigation: removed import and alias.
- CI unsafe‑cast allowlist mismatch
  - Gap: Allowlist referenced `SchemaConformsMacros.scala` (non‑existent). Fix committed: updated to `ContractMacros.scala`.

## High Priority (strongly recommended for v1.0)
- Infrastructure TODOs (observability and config)
  - Tracing: fill TODOs for OTEL span lifecycle, tags, baggage; provide no‑op + real impl behind interface.
  - Config: replace temporary decoder with proper PureConfig mapping; add env/override fallback.
  - Metrics: counters/gauges/timers via Prometheus, registered per stage/pipeline.
- Documentation “Why vs What” clarity for talks and README
  - Add Why‑first slide + runtime vs compile‑time boundary + DX vs process.
  - Include one real production failure story and rollback anecdote.
- Engines Spark boundary tests
  - Expand examples/ITs to cover: idempotent sinks, retry semantics, speculative execution with side‑effects, DQ fallback when Deequ absent.
 - Builder typestate compile‑fail coverage
   - Add negative tests: missing sink/transform, untyped endpoints without SchemaConforms evidence.
 - CI hygiene hardening
   - Lock Spark ITs to JDK 17 (done) and add println-ban for production sources (done). Keep for 2 cycles and revisit exemptions.

## Nice‑to‑Have (post‑v1.0 acceptable)
- Scala 3 macro port for `SchemaConforms` (reduce duplication in core macros).
- Additional connectors (BiqQuery/Snowflake/Kinesis) once abstraction finalized.

## Acceptance Criteria (v1.0)
- Build: green on JDK 17, Scala 2.13 across all non‑Flink modules; Flink built on 2.12 matrix leg.
- Contracts: compile‑fail tests prove drift prevention (exact, backward, forward, ordered/by‑pos) with readable errors.
- Docs: “Start here”, “Why compile‑time?”, and “Public API” consistent; talks include Why and runtime/comptime boundary.
- DX: g8 template compiles, runs a sample, and demonstrates red‑>green flow in < 3 minutes on laptop.
 - Builder typestate: compile‑fail suite proves incomplete pipelines cannot build.
 - CI: Spark ITs pinned to JDK 17; println banned in main sources (examples/CLIs excluded).

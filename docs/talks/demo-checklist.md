# Demo Checklist (Both Talks)

## Local prerequisites
- JDK 17+, sbt 1.9+
- Repo cloned or minimal demo code ready
- Editor/terminal with large fonts

## Commands (Talk B typestate/optionality)
- Prepare code snippet and ensure compile error text is legible
- Screenshot fallback of the error

## Commands (Talk A red->green)
- Show failing compile with strict policy
- Relax to migration policy (Backward/Forward)
- Show compile-fail test + green run

## Projector hygiene
- Dark theme, 24-28 pt monospace
- Maximize terminal/editor; no tiny panes

## Contingencies
- No Wi-Fi: avoid live CI; show screenshot
- IDE glitches: use read-only snippet + prebuilt error output
- Time crunch: skip CI; keep demo to 3-4 min

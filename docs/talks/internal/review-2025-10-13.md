# Talk Review – 13 Oct 2025

> Brutal, unfiltered assessment of the current ScalaIO 2025 decks (Talk A and Talk B). References use repository paths so we can track exactly where the fixes belong.

## Executive Alarm Bells
- The closing sections in both talks still default to **what we built**, not **why anyone should care**. We keep repeating “If it compiles, contracts align” (`docs/talks/modules/talk-a-api-migration.md:S08`, `docs/talks/modules/talk-b-types-validation.md:S08`), but we never tie it back to on-call fatigue, trading-hour risk, or platform credibility. As written, the audience walks away thinking “neat macros” instead of “this saves Friday nights.”
- The boundary slide appears once near the top (`docs/talks/modules/talk-a-api-migration.md:S02`, `docs/talks/modules/talk-b-types-validation.md:S02`), but we never **re-anchor** after the demos. That absence directly fuelled the Q&A confusion between compile-time vs runtime safety and DX vs process. We invited the questions by dropping the thread.
- The personal failure story is tokenised to a single bullet (`docs/talks/modules/talk-a-api-migration.md:S01`). It needs detail, stakes, and emotional weight. Right now it reads like a talking point, not a scar.
- Both decks still feel like **two talks stapled together**. Talk A tries to be migration + contracts + CI; Talk B tries to be types + effects + portability. The “summary” slide in each bundles everything back together instead of staying on message.

## Where the Why Falls Apart
1. **Takeaways are feature recaps.** The punchlines in `S08` for both talks list statements that start with “If it compiles…” or “Let the compiler…”. None of them tell the audience what pain evaporates or what business risk shrinks.
2. **No explicit ROI loop.** After the live demo (`S06`), we fail to say “This is where you get your Friday night back” or “This is how your change-failure rate drops.” The human outcome is missing.
3. **Runtime safety conflation.** We never restate that corruption, SLAs, and retries still live in runtime tooling. Without that reminder the moment we show runtime quality toggles, attendees assume compile-time magic covers everything.
4. **DX vs Process line blurs.** The decks say “DX = fast, Process = gates” once, then we immediately talk about CI screenshots without framing them as process. Listeners understandably mash them together.

## Concrete Fixes (Pre-ScalaIO Lock)
- **Rewrite every closing slide** (`docs/talks/modules/talk-a-api-migration.md:S08`, `docs/talks/modules/talk-b-types-validation.md:S08`) so each bullet is an outcome statement. Examples: “Sleep through Friday deploys because drift dies at compile time,” “Shorten MTTR because error messages point at the exact contract diff,” “Protect data SLAs by keeping retries idempotent at the edges.”
- **Add a recap slide titled “Remember Why” immediately before Q&A** in both talks. Three bullets, all outcome-focused, no implementation nouns. If we must keep the current S08 structure, insert the new slide as `S08b` and move Q&A to `S10`.
- **Expand the scar story into a 45-second script** (two paragraphs) and drop it into `docs/talks/modules/talk-a-api-migration.md:S01` and `docs/talks/modules/talk-b-types-validation.md:S01`. Include specifics: environment, the missing column name, what customers saw, how long the rollback took, who stayed up. Without names/events it does not land.
- **Insert a “Boundary Checkpoint” slide after each demo** (`S06` in both decks). Repeat in bold: “Compile-time stops drift and illegal construction. Runtime still handles corruption, SLAs, retries. DX = local red→green. Process = CI policy gate.” This is the antidote to the compile-time vs runtime confusion.
- **Narrow the message per talk.**  
  - Talk A should stick to migrations + policies + CI guardrails. Drop or demote any effect-system chatter.
  - Talk B should focus on structural typing, typestate, and the pure/effect boundary; punt the engine portability proof to an appendix or a single “yes it works” line.
- **Rehearse the WHY/HOW/WHAT transitions aloud.** Add explicit script lines like “That was the HOW; remember the WHY: we refuse to burn another Friday night.” The decks currently leave that connective tissue implicit.

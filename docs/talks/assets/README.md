# Slide Assets - Rendering Guide

This folder contains ready-to-embed SVGs and sources you can export to PNG for slide embeds.

## Opening Bumper (SVG)
- Preferred: `opening-bumper.svg` (vector; large belief line for first slide)
- Drop on Slide 1 full-bleed; no additional text needed.

## Policy Lattice (SVG/PNG)
- Preferred: `policy-lattice.svg` (vector; works in PowerPoint/Keynote)
- Source table (optional): `policy-lattice.md` (if you want to restyle)
- Export ideas for PNG (optional):
  - Open SVG in Preview and export as PNG; or
  - Use draw.io / Inkscape to export at 2x scale.

## Typestate Builder (SVG/PNG)
- Preferred: `typestate-builder.svg` (vector; works in PowerPoint/Keynote)
- Mermaid source (optional): `typestate-builder.md`
- Export PNG as needed via Preview/Inkscape.

## WHY / HOW / WHAT Circles (SVG)
- Single-message circles ready to drop into slides. Pick the ones you need:
  ### WHY
  - `why-circle.svg` (blank template)
  - `why-01-protect-sleep.svg`
  - `why-02-prevent-drift.svg`
  - `why-03-preserve-trust.svg`
  - `why-04-make-joyful.svg`
  ### HOW
  - `how-01-contracts.svg`
  - `how-02-typestate.svg`
  - `how-03-effects.svg`
  - `how-04-ci-gates.svg`
  ### WHAT
  - `what-01-templates.svg`
  - `what-02-cli.svg`
  - `what-03-connectors.svg`
  - `what-04-engines.svg`
  - `what-05-lineage.svg`
  - `what-06-quality.svg`
- Mix and match or stack as needed. Export to PNG at ≥1600px if vector embeds aren’t supported.

Tip: keep PNG width ≈ 1200–1600px so it stays crisp on projectors.
